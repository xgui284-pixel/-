# 郑帅飞｜视觉设计作品集网页

这是一个单页作品墙网页：所有作品连续展示，不按原文件夹分类。点击任意图片可以全屏查看，并使用键盘左右方向键切换。

## 文件说明

- `index.html`：网页入口
- `styles.css`：页面样式
- `script.js`：图片放大与切换逻辑
- `gallery-data.js`：作品清单
- `assets/`：157 张作品图片

## 发布方式

把整个文件夹上传到支持静态网站的托管服务即可。上传时必须保留 `index.html`、`styles.css`、`script.js`、`gallery-data.js` 和 `assets/` 在同一层级。

如果要长期使用，建议绑定自己的域名，并保留这个文件夹作为本地备份。当前图片使用原图，网页文件夹约 353 MB；正式发布前可以进一步压缩图片，以提升手机访问速度。

## 修改个人信息

打开 `index.html`，可以修改姓名、职位、简介、联系方式和页脚文字。
